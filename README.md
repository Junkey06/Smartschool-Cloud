A cloud-based system called SmartSchool Cloud, hosted on a cloud server and accessible via a WAN (the internet).
It will:
Store all school data (students, attendance, results, announcements) in the cloud (Firebase
Allow teachers, students, and admins to connect from different locations through WAN access.
Provide real-time updates (attendance, results, messages).
Enhance communication and coordination between all school participants.
